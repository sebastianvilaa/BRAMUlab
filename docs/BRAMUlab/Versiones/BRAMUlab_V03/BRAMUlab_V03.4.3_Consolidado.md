# BRAMUlab V03.4.3 — Ajustes finales de cierre (Mis grupos / ubicación)

Pedido directamente en chat (sin archivo adjunto) — transcripto acá tal cual para dejar
registro del alcance de esta ronda, mismo criterio que el resto de `Versiones/`.

## 1. Tabs de Mis grupos

Cambiar "ACTUAL / ANTERIOR / RACE ANUAL" para que usen el mismo tratamiento visual que las
tabs de Historial. No todo en mayúscula. Dejarlo como: Actual / Anterior / Race anual.

## 2. Espaciado en Mis grupos

La tarjeta de BRAMU Intelligence quedó demasiado pegada a la línea/bloque superior. Agregar el
mismo espacio vertical que usamos entre bloques en el resto de la app, para que respire mejor.

## 3. Modales con dos botones en paralelo

En modales tipo "Eliminar grupo", mantener los dos botones uno al lado del otro. Bajar el
tamaño tipográfico de los botones de 14 a 12. Aplicar este criterio a todos los modales
equivalentes con doble acción horizontal.

## 4. Ubicación en Mis datos

En el campo de ubicación no mostrar una lista cargada por defecto al abrir. El campo debe abrir
limpio, solo con placeholder tipo "Buscar localidad..." o "¿De dónde sos?". Mostrar resultados
recién cuando el usuario empieza a escribir. Mantener la lógica actual de guardado y búsqueda
con GeoRef.

Si no aparece nada más raro en la revisión, con esto se da por cerrado este bloque.
